# Mrs. Nimra — Romantic Apology Website

Files:
- index.html
- style.css
- script.js
- romantic-apology.png

Open index.html in a browser to preview.

GitHub Pages:
1. Create a GitHub repository.
2. Upload all four files.
3. Go to Settings -> Pages.
4. Select Deploy from branch, choose main/root.
5. Save and wait for the Pages URL.

Optional music:
Put a file named `romantic.mp3` in the same folder and uncomment the source line in index.html.
